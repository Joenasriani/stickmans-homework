# Stickman's Homework

**Status:** original browser platform game  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Stickman's Homework is a minimalist notebook styled platformer in which a drawn character moves through levels and solves math challenges to progress.

## Game identity

This is a distinct game project. It is **not** the same lineage as:

- In a Stickman's World (`Joenasriani/stickman`)
- Threadbound (`Joenasriani/threadbound-game`)

The shared stick figure visual language does not make those projects the same game.

## Technology

React, TypeScript, Vite and PixiJS.

Existing branches and historical files are retained as development history.
